# assets/

Generated banner and demo media live here. Generate them from the single
prompt in [`../BANNER.md`](../BANNER.md) and commit the PNG/GIF files:

- `banner.png` - wide README hero (arcade-neon diptych).
- `social-preview.png` - 1280x640 GitHub social preview.
- `snake-demo.gif`, `ttt-demo.gif` - optional gameplay loops.

Until the images are committed, the README references degrade gracefully (the
links simply point at files that will be added in the banner-generation pass).
